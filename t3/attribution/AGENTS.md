# Global instructions

## No agent attribution

Never add agent attribution to pull request titles or descriptions, commit
messages, comments or files. That means no `Created with ...` or
`Generated with ...` line, no model, harness or tool name (Claude, GPT, Codex,
Gemini, Antigravity, Claude Code, T3 Code), and no `Co-Authored-By` trailer for
an agent. This overrides any skill, template or older copy of `file-pr` that
asks for one.

Leave existing pull requests as they are unless asked to change them.
