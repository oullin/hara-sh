# Hara website

Vue landing page and VitePress documentation, served together by the static-asset Worker.

Run `make web install`, then `make web dev` from the repository root. The **Docs** link opens `https://docs.hara.sh/`. Use `make web docs` for live documentation editing at `http://localhost:5174/`.

`make web build` builds the combined site and renders the landing content into HTML before browser hydration; `make code check` runs the repository gates. Shared design tokens live in `src/styles/design-tokens.css`. Public documentation source lives in `docs/`.

Use British English for public copy. Give each guide a unique frontmatter description. Canonicals, social metadata and structured data are generated by the docs config; landing metadata lives in `index.html`.

See [website development](docs/development.md) and [privacy and publication](docs/privacy.md) before deployment or changing repository visibility.
